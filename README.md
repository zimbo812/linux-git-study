# Опрацювання теми: Система контролю версій Git

## 1. Що таке Git?
**Git** — це розподілена система керування версіями (DVCS), розроблена Лінусом Торвальдсом у 2005 році для координації розробки ядра Linux. На відміну від централізованих систем (SVN, CVS), Git зберігає повну копію історії репозиторію локально у кожного розробника.

## 2. Основні стани файлів у Git
* **Working Directory (Робоча директорія):** поточні файли, над якими ведеться робота.
* **Staging Area / Index (Індекс):** проміжна зона для підготовки файлів до фіксації.
* **Repository (.git directory):** зафіксовані зміни у вигляді комітів.

## 3. Базові команди для роботи з Git

| Команда | Опис |
| :--- | :--- |
| `git init` | Ініціалізує новий локальний репозиторій у поточній папці |
| `git clone <url>` | Клонує віддалений репозиторій на локальну машину |
| `git status` | Показує поточний стан робочого дерева та підготовлених файлів |
| `git add <file>` | Додає зміни файлу до індексу (staging area) |
| `git commit -m "msg"` | Фіксує підготовлені зміни з коментарем |
| `git branch <name>` | Створює нову гілку |
| `git checkout -b <name>` / `git switch -c <name>` | Створює нову гілку та одразу перемикається на неї |
| `git merge <branch>` | Об'єднує вказану гілку з поточною |
| `git push origin <branch>` | Відправляє локальні коміти у віддалений репозиторій |
| `git pull` | Отримує та об'єднує зміни з віддаленого репозиторію |
