Опрацювання теми: Операційна система GNU/Linux

Практична робота з вивчення базових принципів, дистрибутивів, CLI та скриптингу Bash

1. Коротка інформація про ОС GNU/Linux

GNU/Linux — це вільна Unix-подібна операційна система, побудована на базі ядра Linux, створеного Лінусом Торвальдсом у 1991 році, та системних утиліт проєкту GNU, започаткованого Річардом Столманом у 1983 році.

Основними перевагами системи є відкритий вихідний код (Open Source), висока стабільність, модульність, безпека та гнучкість конфігурації. Сьогодні GNU/Linux домінує в сегменті серверів, хмарних обчислень, суперкомп'ютерів (100% топ-500) та вбудованих систем (включаючи платформу Android).

2. Популярні дистрибутиви Linux

Дистрибутив Linux складається з ядра Linux, утиліт GNU, системи керування пакунками та графічного або консольного середовища. Серед найбільш відомих:

  • Ubuntu — найпопулярніший дистрибутив для домашніх ПК та хмарних рішень, створений на базі Debian компанією Canonical.
  • Debian — один із найстаріших дистрибутивів, відомий бездоганною стабільністю та суворою політикою щодо вільного ПЗ.
  • Fedora — передовий дистрибутив від спільноти, спонсорований компанією Red Hat; тестовий майданчик для нових технологій перед впровадженням у RHEL.
  • Arch Linux — мінімалістичний та легкий дистрибутив, заснований на моделі «rolling release» та філософії DIY (Do It Yourself).
  • Linux Mint — зручна система для початківців, орієнтована на комфортну роботу з мультимедіа та звичний класичний десктопний інтерфейс (Cinnamon).

3. Робота в Linux CLI: Базові команди

Команда Опис призначення Приклад використання
pwd Виводить шлях поточної робочої директорії (print working directory) pwd
echo Виводить переданий рядок тексту на екран або перенаправляє у файл echo "Hello World"
ls Відображає вміст поточної або вказаної директорії ls -la /home
cd Змінює поточну робочу директорію (change directory) cd /var/log
touch Створює порожній файл або оновлює мітку часу існуючого touch script.sh
mkdir Створює нову папку/каталог (make directory) mkdir -p projects/lab1
cp Копіює файли або директорії (з прапорцем -r) cp source.txt backup.txt
mv Переміщує або перейменовує файл чи папку mv old_name.txt new_name.txt
rm Видаляє файли (або папки з прапорцем -rf) rm unnecessary_file.log
history Виводить історію раніше виконаних команд у поточному терміналі history | tail -n 10

4. BASH-скрипт імітації текстової авторизації

Скрипт запитує логін та пароль (без відображення символів), після чого звіряє їх із тестовими даними та виводить відповідний статус доступу:

#!/usr/bin/env bash

# Дані для перевірки
VALID_USER="admin"
VALID_PASS="SuperSecret123"

echo "========================================"
echo "    GNU/Linux Terminal Login System     "
echo "========================================"

# Запит імені користувача
read -p "login: " username

# Запит пароля без відображення символів у терміналі (-s)
read -sp "Password: " password
echo ""

# Перевірка введених даних
if [[ "$username" == "$VALID_USER" && "$password" == "$VALID_PASS" ]]; then
    echo "----------------------------------------"
    echo "Автентифікація успішна! Вітаємо, $username."
    echo "Останній вхід: $(date)"
    echo "Термінал активовано: /bin/bash"
    echo "----------------------------------------"
    exit 0
else
    echo "----------------------------------------"
    echo "Login incorrect. Доступ заборонено!"
    echo "----------------------------------------"
    exit 1
fi
